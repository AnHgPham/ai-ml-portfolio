# Recommended Pinned Repos

GitHub allows up to 6 pinned repositories. The first three should carry the main AI/ML signal; any extra pins should show clean engineering breadth without diluting the Computer Vision and ML systems positioning.

## Recommended Order

1. `computer-vision-pickleball-detection-court`
   - Strongest Computer Vision proof.
   - Shows detection, tracking, homography projection, minimap, heatmap, and annotated video review.

2. `DoAnTotNghiep`
   - Strongest audio ML / graduation-project signal.
   - Shows few-shot enrollment, prototype embeddings, streaming segmentation, thresholding, voting/cooldown, and open-set rejection.

3. `waste_classifier`
   - Strong applied CV project.
   - Shows MobileNetV2, YOLOv8, webcam inference, top-k confidence thinking, evaluation artifacts, and TensorFlow Lite direction.

4. `Job-Market-Android-Java`
   - Good software engineering breadth outside ML.
   - Shows Android, Java, MVVM, SQLite, API integration, and product workflow.

5. `eye_disease_diagnosis`
   - Optional AI depth pin only if the README includes credible dataset, model, evaluation, and limitations.

6. `multi_agent_policy_qa` or `rag-qa-system`
   - Optional LLM/RAG breadth only after the top AI/ML repos are clean.

## Pinning Guidance

- Pin repos that a recruiter can understand in under one minute.
- Prefer 3-4 strong pins over 6 weak pins.
- Put demo evidence near the top of each README.
- Make every pinned repo answer: what problem, what algorithmic pipeline, what output evidence, and how to run or review it.

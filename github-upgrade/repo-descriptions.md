## README Upgrade Pattern

For the three main AI/ML repos, use this structure near the top:

1. One-sentence problem statement.
2. Algorithm pipeline: input -> model/algorithm -> decision logic -> output evidence.
3. Setup and inference command.
4. Demo output: screenshot, GIF, video link, or annotated artifact.
5. Dataset/model notes without overclaiming.
6. Limitations and next steps.
